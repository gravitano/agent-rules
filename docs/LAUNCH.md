### Longer LinkedIn / Threads post

Kalau AI coding agent tidak tahu cara install, test, build, arsitektur, dan batasan project, kita sebenarnya meminta dia menebak.

Malam ini saya merilis **Agent Rules**, tool gratis dan open source untuk menghasilkan instruksi project yang fokus untuk Claude Code, OpenAI Codex, Cursor, Copilot, dan Windsurf.

Isi konteks project, pilih prioritas engineering, lalu dapatkan:

1. `AGENTS.md`
2. `CLAUDE.md`
3. `.cursorrules`

Tidak ada login, backend, analytics, atau upload source code. Semua diproses lokal di browser.

Coba dan kasih tahu preset apa yang perlu ditambahkan berikutnya:
https://gravitano.github.io/agent-rules/
