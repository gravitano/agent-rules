# Product brief — Agent Rules

## Decision

Build a free, privacy-first browser tool that turns a project's real context into three AI coding instruction files: `AGENTS.md`, `CLAUDE.md`, and `.cursorrules`.

## Why this product

### Market surface

The product sits across multiple growing agentic coding ecosystems instead of depending on one vendor: Claude Code, OpenAI Codex, Cursor, GitHub Copilot, Windsurf, and tools that honor `AGENTS.md` conventions.

### Pain

Developers know better context improves AI output, but commonly:

- skip repository instructions entirely;
- copy generic rules that do not mention actual commands or architecture;
- maintain conflicting files for different agents;
- accidentally paste private repository context into hosted prompt generators.

### Wedge

A no-login, local-only guided builder gives an immediate result in under five minutes. Supporting multiple output formats creates a clearer reason to use it than a static template.

### Founder distribution fit

Warsono already teaches Indonesian developers about AI coding workflows and sells adjacent educational products. The tool is useful standalone while naturally demonstrating the value of disciplined AI development.

## Initial ICP

1. Solo developers and small product teams adopting AI coding agents.
2. Technical educators and consultants who need repeatable project setup.
3. Teams piloting multiple coding agents and wanting one shared policy foundation.

## Positioning

> Better instructions. Better AI code.

Generate focused, production-ready rule files for every AI coding agent—privately in your browser.

## MVP scope

- Three presets: SaaS starter, API service, content site.
- Project context, stack, architecture, package manager, test framework, priorities, custom constraints, and commands.
- English and Bahasa Indonesia output.
- `AGENTS.md`, `CLAUDE.md`, and `.cursorrules` generation.
- Copy and individual download.
- Responsive, accessible, SEO-ready static site.
- No backend, auth, analytics, cookies, or data collection.

## Explicit non-goals for v1

- AI-generated text or external API calls.
- Repository import or source-code upload.
- Accounts, cloud saves, team collaboration, or billing.
- Claiming compatibility with every agent-specific instruction format.

## Monetization path

The free tool is a top-of-funnel utility. Validate activation and repeat demand before monetizing.

Potential next layers:

1. Free: generator and curated public presets.
2. Paid template pack: domain presets, review checklists, and team policy packs.
3. Team product: shared policy library, repository sync, versioned approvals, and drift checks.
4. Education funnel: relevant links to Warsono's AI coding ebook/workshop after trust is established.

## Success signals

- Visitors generate at least one file.
- Copy/download actions per visitor.
- GitHub stars, shares, and direct developer feedback.
- Requests for framework, industry, and team presets.

No analytics are included in v1, so initial validation uses opt-in feedback, public engagement, and GitHub activity. Privacy is prioritized over measurement at launch.
